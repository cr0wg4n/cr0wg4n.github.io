I'm sharing some of the best practices and coding guidelines I've learned and collected over the years from working on production projects. I've turned all that knowledge into a set of SKILLS for your AI agent, so it can use them to review, fix, and build your code while following clear guidelines.

I'm excited to say that they're already being used in real projects! Since the project is still new, I'm continuing to test and improve it, but I think it's ready to be shared!!!

Here's the link: [https://github.com/cr0wg4n/dev-skills](https://github.com/cr0wg4n/dev-skills)

Or you can install it with the following command:

```
npx skills add cr0wg4n/dev-skills
```

For now, it contains 4 skills: 2 for Vue and 2 for TypeScript. I'm looking for experienced developers who want to contribute to these skills and expand the knowledge base to support more languages and frameworks 👀.

Feel free to reach out for interesting discussions, improvement suggestions, and new ideas! 🤝

With that said, I'm looking for you: fork it and contribute!

Happy building ⚡
