Estas son algunas de las buenas prácticas y guías de código que he aprendido y reunido a lo largo de los años gracias a mi experiencia trabajando en proyectos en producción. Convertí todo ese conocimiento en distintas SKILLS para  agentes, de tal forma que pueda usarlas al revisar, corregir y construir tu código siguiendo lineamientos claros.

¡Me emociona decir que ya está funcionando en proyectos reales! Como todavía es nuevo, lo sigo probando y mejorando, ¡pero  está listo para compartirse!

Este es el repositorio: [https://github.com/cr0wg4n/dev-skills](https://github.com/cr0wg4n/dev-skills)

o instalalo directamente con el siguiente comando:

```
npx skills add cr0wg4n/dev-skills
```

Por ahora contiene 4 skills: 2 para Vue y 2 para TypeScript. Por lo que se aceptan  desarrolladores con experiencia que quieran contribuir a estas skills y ampliar la base de conocimiento para soportar más lenguajes y frameworks 👀.

¡No dudes en escribirme para tener conversaciones interesantes, sugerencias de mejora y nuevas ideas! 🤝

Dicho esto, te estoy buscando a ti: ¡haz un fork y contribuye!

Feliz desarrollo ⚡
